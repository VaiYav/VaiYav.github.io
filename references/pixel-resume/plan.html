Build Plan

Чем собирать Neon HQ и в каком порядке. Решение опирается на то, что уже нарисовано на бордах, и на замеры веса библиотек.

01 Рекомендация

TypeScript и Canvas 2D без игрового движка, секцией на главной странице сайта на Astro.

Игра маленькая: четыре комнаты, восемнадцать объектов, один герой, столкновения только с прямоугольниками. Всё, что для неё нужно, уже написано в референсах на чистом canvas: спрайты, повороты, камера, диалог, звук. Движок добавил бы сотни килобайт ради возможностей, которыми мы не пользуемся.

three.js тоже не нужен: после перехода к виду сверху в сцене не осталось ничего трёхмерного.

02 Вес вариантов

  • Свой код на Canvas 2D≈ 15 КБ
  • Kaplay 3001.0.1969 КБ
  • PixiJS 8.23.0255 КБ
  • Phaser 4.2.1353 КБ

Размер после gzip. Библиотеки замерены по готовым сборкам из npm, свой код — по текущим файлам референсов (спрайты, сцена, герой, объекты, музыка) без минификации. PixiJS при этом только рисует: ввод, столкновения и звук всё равно писать самим.

Движок стоит вернуть в разговор, если игра вырастет: враги, физика, редактор уровней, десятки экранов. Тогда кандидат — Kaplay.

03 Как это встроено в сайт

Страница и загрузка

  • Секция на главной странице, сразу после полосы с достижениями.
  • Код игры подгружается только после нажатия Start, главная страница не тяжелеет.
  • На сайте включён ClientRouter, поэтому игра запускается по событию astro:page-load и останавливается по astro:before-swap.
  • До релиза секция видна только в разработке; в прод она попадает при PUBLIC_RESUME_GAME=on.

Резюме остаётся резюме

  • Все тексты разделов лежат на странице обычным HTML; canvas — надстройка над ними.
  • Без JavaScript, при prefers-reduced-motion и для поисковиков показывается этот список.
  • «Recruiter CV» — второй пункт меню, ESC ведёт туда из любого места.
  • Диалоги рисуются HTML-поверх canvas: чёткий текст, кириллица, читалки экрана.

Управление

  • Клавиатура: WASD или стрелки, E или Enter — открыть, ESC — выйти.
  • Тач и мышь: тап по полу — идти, тап по объекту — подойти и открыть.
  • Tab проходит по объектам как по обычным кнопкам.

Ассеты

  • Спрайты остаются кодом: сетки с палитрой, без картинок.
  • Портрет запекается при сборке в три готовых кадра, фото в игру не отгружается.
  • Музыка — пока свой синтез на Web Audio, выключена до нажатия кнопки.
  • Пиксельный шрифт Silkscreen не умеет кириллицу: в canvas только латиница, остальное в HTML.

04 Структура кода

src/components/ResumeGame.astro секция: HTML-версия разделов + canvas
src/data/game/content.ts      тексты 18 объектов по языкам
src/data/game/map.ts          комнаты, стены, двери, позиции объектов
src/game/engine/              цикл, ввод, камера, запуск и остановка
src/game/world/               столкновения, «рядом / открыто», прогресс
src/game/render/              спрайты, герой, объекты, фон, портрет
src/game/ui/                  титул, диалог, счётчик, подсказки
src/game/audio/               синт-луп
scripts/bake-portrait.mjs     фото → три кадра портрета
tests/                        Vitest для логики, Playwright для сценария

Файлы короткие и по одной задаче, как требуют твои правила: логика мира отделена от рисования, поэтому её можно тестировать без браузера.

05 Этапы

  1. Каркас

    Секция на главной с HTML-версией разделов, пустой canvas, запуск и остановка при навигации, Vitest и Playwright в проекте.

    Сделано: 21 юнит-тест и 4 сквозных теста проходят, без JS виден список разделов.
  2. Мир

    Данные карты, полы, стены, объекты, герой с анимациями, столкновения, качающаяся камера.

    Сделано: по офису можно ходить с клавиатуры и тапом, стены и мебель не пропускают; 70 юнит-тестов и 11 сквозных проходят; игра запускается кнопкой в шапке и открывается на весь экран.
  3. Взаимодействие

    Состояния «рядом» и «открыто», диалог с говорящим портретом, счётчик найденного, финал после 18 из 18.

    Сделано: любой из 18 разделов открывается клавишей E, тапом по объекту или кнопкой с клавиатуры; тап ведёт героя в обход стен; после 18 из 18 показывается финал. 110 юнит-тестов и 16 сквозных проходят.
  4. Титул, звук, выход

    Титульный экран с меню, кнопка музыки, ESC и пункт «Recruiter CV».

    Сделано: титульный экран со Start и Recruiter CV рядом, меню паузы по Esc и кнопке Menu, кнопка музыки (синт-луп, по умолчанию выключен). 116 юнит-тестов и 21 сквозной проходят на ветке, объединённой с редизайном.
  5. Тексты и языки

    Вычитка твоих формулировок; игра выходит на английском.

    Сделано: все 18 текстов сверены с recruiter-резюме (Soulwise — собственный продукт, три соло-продукта со ссылками, Oboard, консалтинг); дубль заголовка секции убран, у секции остался скрытый заголовок для скринридеров.
  6. Полировка и релиз

    Скорость, доступность, сквозной тест сценария, включение флага в проде.

    Сделано на ветке: на телефоне карта растягивается на всю ширину и остаётся чёткой, кнопки не закрывают карту и диалог; флаг включён в сборке для GitHub Pages. На живом сайте игра появится после слияния ветки в master.
