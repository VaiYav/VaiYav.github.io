03 Сцены

Agent HQ игровой экран

Офис из четырёх комнат. Фиолетовая — опыт и навыки, бирюзовая серверная — AI-агенты, малиновый лаунж с автоматами — проекты, деревянное лобби — контакты.

Герой
Ходит по комнатам, подходит к объекту и открывает раздел резюме.
Агенты
Четыре робота кружат по серверной и лаунжу, у каждого своя реплика.
Выход
ESC или кнопка сразу ведут на обычное резюме.

Титульный экран первое, что видит гость

Имя с двойной тенью, портрет в рамке, меню из трёх пунктов. «Recruiter CV» стоит вторым пунктом, чтобы до текста резюме был один шаг.

Движение
Бегущие полосы фона, пульс заголовка, мигающий курсор, моргание портрета.
Звук
Опционально: короткий синт-луп, выключен по умолчанию.

04 Музыка

Набросок звука. Этот луп сгенерирован прямо в браузере через Web Audio: бас, арпеджио, пэд и драм-машина на 112 BPM. Сэмплов и чужих записей в нём нет, поэтому вопроса прав не возникает.

  • Синтезировать самимКак здесь: несколько килобайт кода, полный контроль, можно менять музыку по комнатам. Звучит проще студийного трека.
  • Сгенерировать ИИ-сервисомБогаче по звуку. Перед публикацией нужно проверить, что тариф сервиса даёт право на публичное использование.
  • Взять готовый трекSynthwave под лицензией CC0 или CC BY из открытых библиотек. Для CC BY нужна подпись автора на странице.

В игре звук выключен по умолчанию и включается кнопкой: браузеры всё равно блокируют автозапуск, а рекрутёр может открыть страницу в офисе.
