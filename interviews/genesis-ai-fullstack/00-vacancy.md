# Genesis · AI Full-Stack Engineer — вакансия и разбор

**Компания:** Genesis (gen.tech) — украинская кофаундинговая IT-компания, паблишер неигровых приложений. 25+ проектов: mobile apps, online media, e-commerce, R&D. №1 в DOU 2024, Forbes — лучший работодатель воєнного часа 2023.

**Команда:** AI R&D Team — небольшая команда, строит **внутренние** AI-продукты для бизнесов экосистемы.

**Их свежие запуски (важно — это якоря для разговора):**
- кост-эффективный LLM-пайплайн для анализа миллионов рекламных креативов
- ClickHouse-движок для процессинга сотен ГБ данных с GitHub
- образовательные платформы с AI-интеграциями для сотен тысяч украинцев

## Что ждут от роли

> "AI Full-Stack Engineer — инженер с продуктовым мышлением, который превращает бизнес-задачи в практические внутренние AI-инструменты."

Работа на стыке: данные → LLM/ML → бэкенд → UI → интеграции → деплой.
Доводит решения от идеи до ежедневного использования командами.

**Контекст важный:** "нет legacy систем", "полный карт-бланш на стек", "доступ к любым ресурсам", "прямой влияние на бизнес".

## Обязанности (5 шт)

1. **End-to-end AI-инструменты** — от сбора данных и LLM/ML логики до бэкенда, UI и деплоя, так чтобы нетехнические команды пользовались сами.
2. **Пайплайны сбора и обработки данных** — гибкий скрейпинг, API-интеграции, кластеризация, NLP-анализ.
3. **Генеративные пайплайны** — кост-эффективные решения для массовой генерации контента (текст, изображения, видео).
4. **Предиктивные ML-модели** — от PoC до прогнозирования бизнес-метрик на визуальных и публичных данных.
5. **Production-ready** — доводить прототипы (включая созданные нетехническими коллегами через AI-ассистентов) до прода: надёжность и безопасность.

## Требования

**Must-have:**
- 2-3+ года коммерческого опыта в Software Engineering (Full-stack/Backend) или ML/Data Science.
- Свободно по всему стеку: ML → backend → UI → деплой.
- Понимание system design, структур данных, "что такое хороший код" (язык/фреймворк — вторично).
- **Уверенное и постоянное использование AI-кодинг ассистентов (Cursor, Claude Code) — как базовый стандарт.**
- Проактивность: бизнес-идея → MVP за неделю без детального ТЗ.

**Nice-to-have (это и есть гэпы которые надо закрывать):**
- Сложные AI-агенты (Agentic workflows, LangGraph)
- Предиктивный ML (XGBoost, LightGBM, нейросети)
- Оптимизация / fine-tuning open-source моделей (LoRA)
- Cloud-инфраструктура (AWS, GCP, Vercel, Docker)
- **Свои продукты с нуля (микро-SaaS, Telegram-боты с реальными юзерами)**

## Сигналы по их свежим запускам

- **LLM-пайплайн для миллионов креативов** = batch processing, prompt caching, провайдер-роутинг, structured outputs. Я делал то же на меньшем масштабе (My Zodiac AI). Спросить: какой объём, какие провайдеры, какая стоимость на 1k креативов?
- **ClickHouse для GitHub данных** = OLAP / аналитика, не моё ядро. Подготовить ответ: "ClickHouse не использовал в проде, но понимаю модель columnar storage; в моих стэках использовал Mongo aggregations и Redis time-series — паттерны те же".
- **AI в обучении для сотен тысяч украинцев** = это, вероятно, под продукты типа Headway/AmoMama/Promova. Имеет смысл загуглить какой именно проект.

## Ключевые риски на мне

1. **Python не основной язык.** У них вероятно ML на Python. Подготовить честный ответ: "Использую Python для скриптов и ML-тулинга, основной прод-бэкенд — NestJS/Node. Паттерны переносимы (DI, async, middleware). За спринт догоню FastAPI / LangChain до прод-уровня."
2. **Predictive ML не моё ядро.** Подготовить: я делаю LLM-based predictions (классификация через few-shot), но XGBoost/LightGBM — это growth area. Покажу понимание когда что использовать.
3. **AWS/GCP на уровне consumer.** Честный ответ: деплоил, использовал S3/Lambda, но не строил MLOps платформ. Готов рампиться.
