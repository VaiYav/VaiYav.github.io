# Короткий рассказ о себе + вопросы

> Для первого звонка с AI Tech Lead.
> Распечатать на 1 страницу, держать перед глазами.

## Короткий рассказ — 60-75 секунд (~180 слов)

> "Я Валентин, Full-Stack Product Engineer, 8+ лет коммерческого опыта. Сейчас работаю на трёх плоскостях параллельно.
>
> Первая — **Soulwise AI** как Full-Stack Engineer. AI-астрология, 10k+ пользователей, web и мобильные. Там я построил RAG на Qdrant, multi-provider роутинг между OpenAI, Claude и Gemini с fallback, prompt caching и batch-генерацию контента. Бандл с 250 до 160 KB ужал, минус 36%.
>
> Вторая — **консалтинг**. Помогаю трём продакт-командам внедрять AI: выбор провайдеров, dependency-матрицы, integration playbook'и. Цель — чтобы команда через 2-4 недели сама вела AI-фичу.
>
> Третья — мой **open-source: speckit-product-forge**. Расширение GitHub Spec Kit для Claude Code. 8 плагинов, 127 skills, 19 sub-agents. Это мой ежедневный production-workflow.
>
> До этого — **4 года в Oboard**, OKR SaaS. Был сеньор-фронт и feature owner: embed в Monday, Salesforce, Jira, Confluence. И параллельно solo построил SaaS **My Zodiac AI** — от нуля до 1500 платящих за 4 месяца.
>
> К вашей вакансии резонирует плотно: внутренние AI-инструменты, AI-кодинг ассистенты как стандарт, end-to-end ownership. Ваш свежий запуск LLM-пайплайна на миллионы креативов — у меня прод-опыт с похожим паттерном."

### Tips по подаче

- **Темп:** ~150 слов в минуту. Не торопись, не тяни. Заранее **проговори вслух с секундомером**.
- **Пауза после "трёх плоскостях":** дай Tech Lead'у поймать структуру.
- **Не читай с листа.** Пусть лист будет рядом, но смотри в камеру.
- **Закончи на резонансе с их задачей** — это invites их первый углубляющий вопрос на твою территорию.

## Follow-up вопросы которые скорее всего зададут ПОСЛЕ рассказа

Tech Lead вытянет одну из плоскостей в углубление. Готовь короткие точные ответы:

### По Soulwise

1. **"Расскажи подробнее про multi-provider routing — как выбираешь между OpenAI, Claude, Gemini?"**
   - По cost/quality/latency треугольнику. OpenAI primary для structured output (JSON schema strict mode). Claude для длинного контекста и сложного reasoning. Gemini Flash для дешёвых batch-задач. Fallback на лету если основной отвечает >5sec или 5xx.

2. **"Как у тебя устроен RAG в Soulwise?"**
   - Qdrant как vector DB. text-embedding-3-small для embeddings. Semantic chunking. Payload filtering по знаку зодиака + локали юзера. На запросе — embedding query → top-K из Qdrant → промпт. Hybrid search не делал — на этом домене не нужно было.

3. **"Какой главный технический challenge встретил?"**
   - Multi-provider адаптеры: разные провайдеры — разные форматы structured output, разные rate-limits, разные retry-поведения. Сделал слой адаптеров с унифицированной схемой ответа, idempotency keys, feature flag кто primary.

4. **"Как 250→160 KB сделал?"**
   - Route-based code splitting + dynamic imports для i18n + tree-shaking аудит + lazy charts + перенос heavy частей на server components.

### По Консалтингу

5. **"Что значит 'AI dependency matrix' конкретно?"**
   - Таблица "кто за что отвечает" по 4 уровням: model provider, infra, data pipeline, product layer. На каждый — кто owner, какой SLA, какой fallback. Помогает командам не терять ничего сквозь "не моя зона".

6. **"Что в integration playbook'е?"**
   - Пошаговый guide первой AI-фичи: какой провайдер выбрать, как развернуть API key management, паттерны caching, observability minimum, eval-флоу. С code samples под их стек.

### По speckit-product-forge

7. **"Зачем 127 skills, не overkill?"**
   - Каждая skill — узкая функция (типа "сгенерировать API changelog" или "проверить i18n coverage"). Composability: agent выбирает релевантные комбинации под задачу. Альтернатива — один монолит-промпт, что хуже работает.

8. **"Какие sub-agents — пример?"**
   - market-researcher, ux-researcher, tech-researcher для исследований; vue-reviewer, nestjs-reviewer для code review; build-resolver для CI ошибок. Каждый имеет свой system prompt, свой toolkit, свою модель (Haiku для простых, Sonnet для сложных).

9. **"Используют ли другие команды твой инструмент?"**
   - Open-source на GitHub. Я подключал к Soulwise и к консалтинговым клиентам. Adoption отслеживаю через GitHub stars и issues.

### По Oboard / My Zodiac AI

10. **"Почему ушёл из Oboard?"**
    - Не "ушёл из-за плохого" — а "пошёл к большему": хочу AI-first контекст и больше масштаба. В Oboard я закрыл всё что хотел: ownership 4 года, embed в 4 платформы, mentoring. Дальше расти там — означало бы менеджмент. А я хочу остаться инженером.

11. **"My Zodiac AI — почему именно астрология?"**
    - Конкретный сегмент с реальным спросом, низкая конкуренция в UA/RU, понятная экономика (subscription). Хотел проверить full ownership solo — астрология дала пространство.

12. **"Что не получилось в My Zodiac AI?"**
    - Пытался идти на англоязычный рынок против Co-Star — не зашло за 2 месяца. Перепозиционировал на UA/RU — пошло. Урок: не воюй с established competitor на их территории.

## Мои вопросы к Tech Lead — топ-5 (must-ask)

Из всего списка в `03-questions-to-ask.md` — вот пять которые **обязательно** задать на этом звонке:

### Открывающий (первые 5 минут разговора)

1. **"Прежде чем глубоко погружаться — расскажи кратко, что сейчас на столе у AI R&D Team? Какие 2-3 активных проекта?"**
   > Калибрует остаток разговора. Ты говоришь про свой опыт прицельно под их боль.

### В середине (технические)

2. **"Какие LLM-провайдеры сейчас в проде и какое распределение по нагрузке? Что primary, что fallback?"**
   > Показывает что ты мыслишь архитектурно про cost/reliability.

3. **"Как у вас построен AI cost guard и eval-флоу? Какой стек — Langfuse, LangSmith, custom?"**
   > Сильный сеньорский вопрос. Тех-лиды это любят.

### Ближе к концу (про роль)

4. **"Какой первый проект если я выхожу, и что для тебя значит 'успех через 60 дней'?"**
   > Конкретика. Заставляет Tech Lead'a проговорить ожидания.

### Самый последний (closing)

5. **"Какие у тебя остались сомнения по моей кандидатуре после нашего разговора?"**
   > Сильный move. Снимает скрытые блокеры. Не каждый кандидат осмелится — выделит тебя.

## Backup вопросы (если разговор пошёл живо и есть время)

- "ClickHouse у вас — шаренный кластер всей экосистемы или dedicated AI R&D?"
- "Команда уже использует AI-codegen ежедневно или это только начинается? Есть свои internal skills/agents?"
- "Что у вас 'плохо' — где команда слабая, что хочется усилить?"
- "Какая последняя AI-фича которой ты лично гордишься? Что было сложнее всего?"

## Минимум который надо узнать к концу звонка

После звонка у меня должны быть ответы на:

- [ ] Какой их основной AI-стек (TS / Python / mix)
- [ ] Какой первый проект для меня (хотя бы направление)
- [ ] Зарплатный диапазон (хотя бы вилка)
- [ ] Следующий шаг и timeline
- [ ] Кто будет смотреть тестовое

Если ответов нет на 3+ — я плохо вёл разговор.

## Финальный mental check за 30 секунд до звонка

> "Я не сдаю экзамен. Я знакомлюсь с человеком и проверяю, подходит ли мне эта работа.
> Они показывают что у них, я показываю что у меня.
> Я уже 8 лет в индустрии, у меня прод-опыт по их главным темам, и у меня сейчас есть параллельный доход.
> Это разговор равных, не оценка."
