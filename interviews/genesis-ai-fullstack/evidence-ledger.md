# Genesis — evidence ledger

Цей файл — джерело правди для співбесіди. Не називати цифру, інструмент або результат production-досвідом, якщо він не підтверджений CV чи власним досвідом.

## Підтверджено

- 8+ років у full-stack/product engineering.
- 2+ роки у production AI, LLM та agent systems.
- Soulwise AI: 10k+ користувачів; OpenAI, Claude, Gemini; Qdrant; Capacitor; bundle 250→160 KB, приблизно −36%; strict TypeScript та automated testing.
- Oboard: близько 4 років, feature ownership, Monday.com/Salesforce/Jira/Confluence, payments, внутрішні інструменти, близько −40% manual work.
- My Zodiac AI: solo 0→1 SaaS, 1500 платних користувачів за 4 місяці.
- AI consulting: 3 продуктові команди, AI roadmaps, dependency matrices та integration playbooks.
- speckit-product-forge: власний open-source spec-driven workflow для AI coding agents.

## Чесні gap-відповіді

- Python/FastAPI: використовую для scripts і ML tooling; основний production backend — TypeScript/NestJS.
- LangGraph: будував еквівалентні agent/tool-use flows на raw SDK; framework-specific ramp-up закрию швидко.
- XGBoost/LightGBM: експериментальний/Kaggle-рівень, не production ownership.
- LoRA: теорію та Colab-експерименти знаю; не продаю це як production fine-tuning.
- AWS/GCP: consumer-level deployment; не будував MLOps-платформу.
- ClickHouse: не використовував у production; розумію OLAP/columnar trade-offs.

## Головний меседж

Я перетворюю бізнес-проблему на production AI-інструмент: уточнюю сценарій, швидко збираю MVP, проєктую data flow та API, додаю валідацію, eval, cost/reliability controls і доводжу результат до щоденного використання командою.
