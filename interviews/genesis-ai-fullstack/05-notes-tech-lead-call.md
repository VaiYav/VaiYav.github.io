# Звонок с AI Tech Lead — конкретная подготовка

> Первый этап у Genesis. Не intro, а **techical знайомство**. От этого звонка зависит — пускают ли на тестовое (а это ~25% воронки).
> Длительность обычно 45-60 мин. Tech Lead ведёт.

## За 24 часа до звонка

- [ ] Прочитать ещё раз `04-genesis-research.md` — особенно блок "Что ценят" и "красные флаги"
- [ ] Прочитать `CHEATSHEET-QUICK.md`
- [ ] Освежить `_cheatsheets/01-llm-pipelines.md` (их свежий запуск)
- [ ] Освежить `_cheatsheets/10-system-design-ai.md` (могут попросить нарисовать)

- [ ] Открыть My Zodiac AI live (если live) — на случай если попросят показать
- [ ] Подготовить **зарплатный номер** (см. ниже)
- [ ] Загуглить **имя Tech Lead** — LinkedIn, что писал/публиковал

## За 1 час до звонка

- [ ] Чашка воды на столе. Туалет.
- [ ] Тишина в комнате. Headphones.
- [ ] Камера, фон, свет — проверить.
- [ ] Текст 2-min self-pitch перед глазами (бумага), **но НЕ читать с экрана**
- [ ] 3 STAR-кейса свернуты в bullet-points (My Zodiac AI, Soulwise, Oboard)
- [ ] Чек-лист "что хочу спросить" (см. ниже)
- [ ] 5 глубоких вдохов перед звонком

## Что Tech Lead скорее всего спросит (по приоритету)

### Блок 1: Background (5-10 мин)

1. **"Расскажи о себе"** → 2-min self-pitch
2. **"Что сейчас делаешь в Soulwise / в консалтинге?"** → конкретики
3. **"Почему ищешь работу?"** → честно: "Solo solo SaaS дал мне свободу действовать, но я хочу масштаба и команды. У вас одни из лучших R&D-команд в UA"
4. **"Расскажи про speckit-product-forge — что это и зачем?"** → возможность блеснуть

### Блок 2: Deep-dive в проект на твой выбор (10-15 мин)

5. **"Какой твой самый сложный технический challenge за последний год?"**
   - Заготовка: multi-provider LLM routing в Soulwise (см. 02-self-pitch.md, последний блок)
6. **"Покажи pull-request / архитектурное решение которым гордишься"**
   - Заранее открой 1-2 PR в браузере, готов показать
7. **"Как ты пришёл к этому решению — какие альтернативы рассматривал?"**

### Блок 3: AI specifics (10-15 мин) — критично!

8. **"Какие LLM-провайдеры использовал и как выбираешь между ними?"**
   - Ответ: OpenAI primary, Claude fallback / для длинного контекста, Gemini Flash для batch. Выбор — по cost/quality/latency треугольнику.
9. **"Как мерил качество LLM-выхода в проде?"**
   - Schema-pass rate (бесплатно, всегда) + LLM-as-judge (10-20% sample) + golden dataset для регрессий
10. **"Что такое RAG и где применял?"** → коротко по cheat sheet 02
11. **"Делал ли fine-tuning?"** → честно: "Прогонял QLoRA в Colab, в проде не деплоил. У клиентов API всегда оказывался дешевле для их volume" + следом сразу когда оправдан fine-tune
12. **"Делал ли predictive ML (XGBoost, нейросети)?"** → честно: "Kaggle уровень, в проде классификацию решал через LLM + embeddings. Знаю когда переключаться: устойчивые числовые фичи + большой dataset + < 100ms inference = LightGBM"
13. **"Знаком с LangGraph / LangChain?"** → "Концептуально yes, в проде делал на raw Anthropic SDK — те же паттерны: state machine, tool use, fallback. LangGraph закрою за спринт если это стандарт у вас"

### Блок 4: System design (5-15 мин) — могут попросить порисовать

14. **"Если бы тебе сегодня дали задачу: проанализировать 1M рекламных креативов с помощью LLM — как бы построил?"**
    - Это **их свежий запуск**. Готов отвечать детально:
    - Architecture: source → queue → workers → cache → cascading LLM (Haiku/Flash → Sonnet) → structured output → storage → UI
    - Cost estimate: ~$5-7k на 1M с caching + batch (см. 01-llm-pipelines.md)
    - Trade-offs: managed API vs self-host (для 1M в день — API; для 30M+ в день — рассмотрел бы self-host fine-tune)
    - Tools: Langfuse + Sentry для observability
    - **Лайфхак:** возьми листок и попроси разрешение порисовать. Это показывает engineering thinking.

15. **"Что бы ты делал в первый месяц если выйдешь к нам?"**
    - "Зависит от того что назвал как первый проект. В общем — первая неделя: shadow команду, понять кост-структуру и eval-флоу, найти 'низковисящие фрукты' (caching, prompt versioning, observability gaps). Вторая-четвёртая — закрыть один конкретный proj end-to-end. Не пытался бы перестраивать архитектуру в первый месяц."

### Блок 5: Soft skills (5-10 мин)

16. **"Расскажи про конфликт с прошлым работодателем"** → **ШАБЛОН ДЕНИСЮКА** из 04-research.md:
    > "В Oboard ми проходили перебудову команди фронтенду. Я не погоджувався з одним рішенням про вибір технології — я бачив що це додає складності для нетехнічних користувачів. Я зробив POC alternativ'і, показав цифрами, але рішення залишилось колишнім. Зараз я розумію, що тоді у CEO був стратегічний контекст (партнерство), який я не бачив. Я б діяв так само — POC + цифри — але приймав би рішення компанії спокійніше."

17. **"Что читаешь сейчас / какие источники следишь?"**
    - **Книги:** "Designing Machine Learning Systems" — Chip Huyen, "The Manager's Path" — Camille Fournier
    - **Подкасты:** Latent Space, The Pragmatic Engineer
    - **Блоги:** Simon Willison, Hamel Husain (eval-driven dev), Eugene Yan (ML system design)
    - Это не флекс — это реально то что читаешь. Если не читаешь — начни **сегодня** прежде чем врать.

18. **"Что не получилось в твоей карьере? Какая самая болезненная ошибка?"**
    - Кейс: **My Zodiac AI** — пытался конкурировать с Co-Star напрямую (англоязычная аудитория), не зашло. Потерял ~2 месяца. Перепозиционировал на UA/RU аудиторию — пошло. Урок: не воюй с established competitor на их территории, найди недообслуженный сегмент.

19. **"Расскажи про работу в команде — где ты last был сильным command player?"**
    - Oboard: 4 года, 2 фронт + 5 бэк. Я был тех-лидом фронтенда + feature owner. Не "я делал" а "мы строили". Конкретный пример: rebuild OKR-дашборда — спецификация с продактом, дизайн с дизайнером, реализация с другим фронтом, контракт API с двумя бэкендерами. Срок 6 недель, делайн встретили.

### Блок 6: Их вопросы → твои ответы про мотивацию

20. **"Почему именно Genesis, не [конкурент]?"**
    - Конкретно: "Внутрішні AI-продукти для бізнесов — рідкість. Обычно AI билдят B2C. Здесь команды/процессы — это интересно мне как инженеру с продакт-mindset. Плюс экосистема — потенциал расти из AI R&D в продуктовую вертикаль через 1-2 года. Я следил за Headway и Promova как пользователь — впечатляюще."

21. **"Где ты видишь себя через 2 года?"**
    - "Принципал AI Engineer / AI Lead с командой. Хочу влиять архитектурно на 5-10 проектов параллельно, не на одном. Genesis даёт ту мульти-проектную сцену для этого."

22. **"Что для тебя deal-breaker?"** (могут не спросить, но готов)
    - "Микроменеджмент. Я работаю автономно. Дайте задачу и контекст, спросите результат — я доставлю. Если нужны daily-statusы или одобрения на каждое решение — не подойдём друг другу. По другим вопросам гибок."

## Что НЕ делать

- ❌ Зависать на одном кейсе > 3 минут — переходи к следующему
- ❌ Использовать buzzwords без объяснения зачем (RAG, vector DB, agent — каждый раз short purpose)
- ❌ Говорить что-то типа "Я лучше всех в Vue" — звучит фальшиво, лучше "8 лет ежедневной практики"
- ❌ Жаловаться на Oboard / Soulwise / клиентов
- ❌ Спрашивать про зп в первые 20 минут
- ❌ Спрашивать про релокацию / визы (это не AI Tech Lead'a проблема)
- ❌ Молчать когда не понял вопрос — переспроси

## Зарплатный номер — подготовь

В Genesis вилки обычно (по DOU данным):
- Senior Full-Stack: $4500-6500 USD net / мес
- Senior с AI specialty: +20-30%
- Lead: $6500-9000+

**Моя позиция:** AI Full-Stack Senior+ = ~**$5500-7500 USD net / мес** в моих оценках. С учётом open-source + solo SaaS — обоснованно target middle-upper.

**Скрипт ответа когда спросят:**
> "Мой текущий range — $X-Y USD net в месяц. Это с учётом моего опыта 8 лет, открытого инструментария на GitHub, и параллельных консалтинг-контрактов. Гибок по цифре в зависимости от других условий — equity, growth path, обязанности."

Не называй одну цифру — называй вилку. Дай им место для манёвра.
