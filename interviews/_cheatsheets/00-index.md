# Cheat Sheets — индекс

Тематические шит-шиты по AI/ML/инфра, актуальные на 2025-2026. Каждый файл — самостоятельный, можно читать за 15-20 минут перед звонком.

## Структура каждого cheat sheet

1. **Что и зачем** — суть в 2 абзацах
2. **Как устроено** — архитектура / компоненты
3. **Состояние рынка в 2025-2026** — что популярно, что устарело
4. **Best practices** — как правильно делать сейчас
5. **Подводные камни** — типичные ошибки + о чём спросят на собесе
6. **Что сказать на собесе** — мой реальный опыт + честный ответ
