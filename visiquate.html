Product Forge — architectural pattern for LLM-first systems

My open-source framework
Open framework · v1.5.1 · MIT

An architectural pattern for systems where LLMs are the core, not a feature.

Product Forge is a 29-command framework on top of GitHub Spec Kit. The interesting part is not the commands — it's the architecture: loosely coupled sub-agents composed via skills and plugins, per-phase context digests that keep model windows manageable across long flows, a state-lock protocol for concurrent writes, a 7-layer drift detector, and a full traceability chain (problem → research → spec → code → tests → metrics).

Relevant to VisiQuate's healthcare focus: ships with a V-Model execution mode designed for regulated software — IEC 62304 (medical), ISO 26262, DO-178C — where requirement → architecture → design → test traceability is mandatory for audits. Same framework, different rigor profile.
